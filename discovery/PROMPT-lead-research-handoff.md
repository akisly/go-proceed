# Промпт для передачи поиска лидов другому агенту

Скопируйте всё ниже разделителя. Промпт самодостаточен: агенту не нужен контекст предыдущей
сессии.

---

## Задача

Найти новых квалифицированных лидов для холодной рассылки AktFlow — украинских монтажных
подрядников, у которых доказательства выполненных работ (фото, объёмы, согласования) теряются
до того, как работы становятся скрытыми или недоступными для проверки.

Это **исследование**. Ты не пишешь письма, не отправляешь их и не трогаешь Gmail.

## Абсолютные запреты

- **Никогда не угадывай, не выводи и не конструируй email.** Нет `firstname.lastname@`, нет
  `info@`, придуманного из домена. Если публичного делового адреса нет — лид `unreachable`.
- **Только публично опубликованная информация.** Никаких купленных баз, скрейпинга за
  авторизацией, обхода paywall, личных (не деловых) адресов.
- **Не выдумывай факты, чтобы заполнить поле.** Пусто лучше, чем неверно.
- **Не создавай аккаунтов** ни на каких сервисах.
- Никаких Gmail-меток, черновиков, отправок. Никакой работы с веткой `feat/p0a-child-a-prototype`.

## Стандарт квалификации: три измерения, все обязательны

Лид квалифицирован, только когда **каждое** из трёх подтверждено отдельно. Для каждого открой
источник и убедись, что он подтверждает именно это утверждение, затем запиши, **что именно на
странице** его подтверждает.

| Измерение | Что значит «подтверждено» |
|---|---|
| **Идентичность** | Названное юрлицо — это та самая компания. Реестровая запись или собственные реквизиты на её сайте |
| **Специализация** | Компания **сама выполняет монтаж** в указанной отрасли. Её собственный сайт или запись о победе в тендере. **Код КВЕД сам по себе этого не подтверждает никогда** |
| **Публичный деловой контакт** | Деловой email опубликован **дословно** на собственном домене компании или в официальном каталоге |

**URL, который существует, но не подтверждает утверждение, — не подтверждение.**

Сумма не заменяет отсутствующее измерение. Лид с подтверждённой идентичностью и специализацией,
но без контакта — не квалифицирован, и никакой балл этого не меняет.

Бесплатные ящики (`gmail`, `ukr.net`, `i.ua`) **не являются основанием для отказа**, если компания
сама опубликовала их как деловой контакт. Записывай как риск доставляемости.

## Дисквалификаторы

`D1` генподрядчик/застройщик без собственного монтажа · `D2` нет полевых работ · `D3` торговля,
дистрибуция, производство без собственного монтажа · `D4` только проектное бюро · `D5` нет
публичного делового email (**восстановимо**, статус `unreachable`, перепроверка через 90 дней) ·
`D6` не работает в Украине или неактивна (последний датированный материал старше 24 месяцев) ·
`D7` ФОП без бригады · `D8` дубликат · `D9` в списке подавления.

## Разведка по источникам: что работает, что нет

Это самое ценное здесь. Сэкономит тебе дни.

### Работает

| Источник | Как использовать | Выход |
|---|---|---|
| **Каталог АСЕУ** `catalog.aseu.org.ua/node/N` | Профили публикуют название, регион, сайт, email. Официальный отраслевой каталог | **67% квалификации** — лучший показатель. Страницы 2–6 (~61 профиль) не разобраны |
| **ua-region.com.ua/kved/{код}** | Каталог по КВЕД: название, ЄДРПОУ, город, ссылка на свой сайт. **Только для поиска кандидатов, не как доказательство** | ~35% квалификации |
| **ProZorro (открытый API)** | Метод ниже. Даёт идентичность, специализацию и датированную активность из официального реестра | Идентичность 96%, но контакт **не даёт** |
| **work.ua** | Поиск «інженер ПТО», «інженер ВТВ» — 144 вакансии, у работодателей видны названия и **даты** | Датированный сигнал отличный, но у большинства работодателей нет сайта |
| **data.gov.ua** | Выгрузка ЄДР доступна без входа | Не проверялось на объёме |

### Метод ProZorro (проверен, работает)

```
1. GET https://public.api.openprocurement.org/api/2.5/tenders
        ?descending=1&opt_fields=tenderID,status[&offset=<ISO-timestamp>]
   Возвращает по 100 записей: {dateModified, id (UUID), tenderID, status}
2. Оставить status in {complete, active.awarded}
3. GET https://public.api.openprocurement.org/api/2.5/tenders/{uuid}
4. CPV читать из classification.id ИЛИ items[].classification.id
   (на priceQuotation classification пустой — иначе молча потеряешь эти тендеры)
5. Подрядчик — в awards[] где status == active → suppliers[]
   Там identifier.legalName и identifier.id (UA-EDR)
6. contracts[] внутри тендера НЕ содержит ключа suppliers. Не ищи там.
7. Дедуп по identifier.id. Длина 8 = ЄДРПОУ (юрлицо), длина 10 = ІПН ФОП → D7
```

CPV для монтажа: `45310` `45311` `45312` `45313` `45314` `45315` `45316` `45317` (электрика,
пожарная сигнализация, СКУД, автоматизация), `45330` `45331` (сантехника, ОВиК), `45231` `45232`
(трубопроводы).

**Ловушка:** параметр `?tenderID=` API **молча игнорирует** и отдаёт HTTP 200 с посторонней
лентой с 2015 года. Не принимай это за фильтрацию.

**Ограничение:** ProZorro **не даёт пригодного адреса для рассылки.**
`suppliers[].contactPoint.email` — это именной контакт человека, ответственного за закупку, часто
личный. Использовать его для холодного письма нельзя. Адрес ищи отдельно на сайте компании.

### Не работает — не трать время

| Источник | Причина |
|---|---|
| Clarity Project | Paywall, от 450 грн/сутки |
| YouControl | Бесплатный тариф требует регистрации аккаунта |
| Opendatabot | HTTP 403 на автоматический запрос |
| Веб-интерфейс ProZorro | SPA отвергает версию браузера, фильтры не рендерятся. Только API |
| Ajax Systems и прочие вендорские «каталоги установщиков» | Публичного списка установщиков нет, только логин в партнёрский портал |

### Чего ожидать по провалам

Калибруй ожидания по прошлому проходу:

- **13% компаний не публикуют делового email вообще** (только телефон, Viber, Telegram)
- **19% сайтов не открываются** — просроченные, самоподписанные или несовпадающие TLS-сертификаты,
  403/404/500, мёртвый DNS. Это артефакт автоматизации, а не факт о компании. Записывай как
  `researching` с технической причиной, **не** отклоняй по ICP
- У лидов из ProZorro провал по контактам **70%**

## Что нужно искать сейчас

**Приоритет по отраслям** (в пуле уже 15 electrical_group и 8 solar):

| Отрасль | Нужно | Комментарий |
|---|---|---|
| `electrical`, `low_voltage` | **больше всего** | Основной клин. Демо построено на электромонтаже |
| `hvac` | 3–5 | В пуле 2 |
| `plumbing` / инженерные сети | 3–5 | В пуле 1. Закопанные трубопроводы — сильнейший случай задачи |
| `maintenance` | 2–3 | В пуле 2 |
| `solar` | **не искать** | Уже перебор |

**Общая задача, по которой оцениваются все отрасли одинаково:**

> Не дать потерять обязательные фото, документы, объёмы и согласования до того, как выполненные
> работы станут скрытыми, недоступными или трудно проверяемыми.

Для каждого лида запиши конкретный экземпляр этой задачи, а не пересказ формулировки: «кабель в
стяжке до заливки», «контур заземления в грунте», «воздуховоды за подвесным потолком»,
«трубопровод в траншее до засыпки».

Ищи признаки: скрытые работы, внешняя приёмка (генподряд, госзаказчик, технадзор), вакансии
инженера ПТО/ВТВ, датированная активность за последние 12 месяцев.

## Условие остановки

Останавливайся, когда выполнено одно из двух:

1. **15 новых полностью проверенных лидов** квалифицированы; либо
2. **60 уникальных компаний изучено в глубину**, все перечисленные источники материально
   отработаны, и задокументирована причина, почему больше нельзя получить, не снижая стандарт.

**Не продолжай ради цифры.** Отчёт о недоборе с честными причинами ценнее добитого числа.

Количество найденных и изученных в глубину · квалифицировано · отклонено с разбивкой по причинам ·

**Не интерпретируй выход квалификации как спрос.** Он измеряет, сколько компаний удалось найти и
проверить по публичным источникам. О готовности покупать он не говорит ничего — ни за, ни против.
Это разные вещи, и путать их нельзя.
