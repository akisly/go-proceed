# DEV-028 — The Autumn palette and the brand sheet's typeface

## Assignment

- Objective and user-visible outcome: the design system and the landing take the owner's brand sheet — a warm neutral ramp from `#0C0C0A` to white on paper `#ECE9DF`, the deep green `#395A4D` as the PRIMARY brand colour and the orange `#FF5B04` as the SECONDARY, set in Hanken Grotesk. Every surface that reads a token role changes with it: the landing's four pages, the office dashboard, the field client's icons and manifests, and `DESIGN.md`.
- State: verifying
- Coordinator: primary session (Claude Code, Opus 5)
- Execution mode: independent subagents for the stages root `AGENTS.md` requires
- Selected route and why (`agents/COORDINATION.md`): design-system route — the change starts in `packages/tokens` and reaches every app through generated artefacts, so it is one token change plus the files that name a colour or a family outside the token source.
- Triggered stages and why: `gp-reviewer` (always), `gp-ui-reviewer` (`apps/landing`, `packages/ui`, `packages/tokens`), `gp-qa` (always). No `gp-architect` (no table, contract, catalog or policy), no `gp-security` (no auth, RLS, secret, CI permission or personal data; the `.env*` files are untouched), `gp-mobile` — **added after review** (`gp-reviewer` R-12): root `AGENTS.md` lists `apps/mobile` as a trigger in its own right, and the change edits `app.json`, the web manifest, the html finaliser and six icon rasters. The first draft of this line argued the trigger had not fired because installability and capture behaviour are unchanged; that reading ignored the standalone trigger and is corrected here.
- Owning module and allowed edit paths: `packages/tokens`, `packages/ui`, `packages/testing`, `apps/landing`, `apps/app` (layout, manifest, icons, QA harness), `apps/mobile` (icons, `app.json`, web manifest, the html finaliser), `design-references/brand`, `DESIGN.md`, `docs/design/02-building-ui.md`, `docs/tasks/`.
- Read context and applicable local instructions: `AGENTS.md`, `docs/design/02-building-ui.md`, `docs/design/01-tokens.md`, `DESIGN.md`, `apps/landing/AGENTS.md`.
- Linked spec, ADR or earlier task: DEV-027 (the landing's behaviour, committed as `88ac0a3`), DEV-026, DEV-025.
- Baseline: `88ac0a3` — «feat(landing): DEV-027 — the reference's behaviour, not its stills», committed at the owner's instruction at the start of this task so that the palette arrives as its own diff.
- Dependencies / constraints / out of scope: no push, no PR, no merge. Dark mode stays authored and unshipped (D6). The full `@goproceed/testing` suite is not run — it resets the owner's local database. `apps/app`'s browser harness needs database credentials this worktree does not have.
- Required acceptance criteria:
  1. Every primitive colour is an OKLCH triple whose committed hex the maths reproduces, in gamut, with distinct steps per ramp.
  2. The brand sheet's four declared values are reproduced exactly: `#ECE9DF`, `#0C0C0A`, `#FF5B04`, `#395A4D`.
  3. Every semantic pairing still clears its contrast obligation, in both themes (`contrast.test.ts`, 80 assertions).
  4. Pine is the primary: brand, link, focus ring, accent phrase, and every ornament on the landing.
  5. Ember is the secondary: the one accent action (ink on orange, never white) and the pill's travelling light. *[Amended 2026-09-22: «the brand dot» was in this criterion until the owner moved the dot to the primary — «сделай кнопку в лого зеленой, а текст черным».]*
  6. No status colour can be read as a brand colour: attention, blocked and ready stand a stated distance from ember's hue, and the ready green stays saturated where pine is not.
  7. Hanken Grotesk carries every Latin glyph and digit; Commissioner carries Cyrillic; the order is asserted, not assumed.
  8. No hard-coded palette hex survives outside the token source and the brand SVG masters, and every generated artefact is regenerated byte-exact.
  9. The gate: `motion-audit`, `typecheck`, `build`, the landing suite, the static suites, the landing harness, `validate:canonical-docs`.
  10. `DESIGN.md` and `docs/design/02-building-ui.md` describe the palette and the faces that ship.
- Skipped stages and rationale: recorded above.

## Plan

1. Commit DEV-027 (`88ac0a3`), so the palette is a separate diff. — `git log`
2. Verify the typeface before designing anything: parse Hanken Grotesk's own file for Ukrainian coverage, and measure candidate Cyrillic faces against it. — the measurements in «Sources»
3. Sample the brand sheet for the ramp and the paper; convert the declared values to OKLCH with the repository's own maths. — `packages/tokens/scripts/lib/color.mjs`
4. Rewrite `primitive.color`: the warm neutral ramp, the new `ember` and `pine` ramps, the moved status families, cobalt demoted to the review state. Every step gets a ruling with its measured ratios. — `palette-derivation.test.ts`, `token-fidelity.test.ts`
5. Re-point the semantic roles: pine primary, ember secondary, ink on the signal ground. — `contrast.test.ts`
6. Move the shadow colours, regenerate all seven artefacts. — `token-fidelity.test.ts`
7. Rewrite the two guards that pinned the old palette (the Daylight anchors; «paper warm, ink cool»), and add the guards the owner's distance decision needs. — the suite itself
8. The faces: subset files for the landing, the package pair for `apps/app`, the token stack, the overrides, the tests and the app harness. — `fonts.test.ts`, `design-contract.test.tsx`
9. Everything that names a colour outside the token source: the brand SVG masters and the 16 rasters, three manifests, two `themeColor`s, the Safari mask tint, the mobile splash and adaptive icon.
10. The pill's travelling light moves from the accent to the signal, because the primary measures 2.55:1 on a near-black pill.
11. The wordmark takes `text-brand`, so the sheet's green is on the page and not only in the token file.
12. `DESIGN.md` and `docs/design/02-building-ui.md`.
13. The gate, the harness, then the three independent stages.
